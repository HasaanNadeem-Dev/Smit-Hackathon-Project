# HelpHub AI 🚀

> **Find help faster. Become help that matters.**

HelpHub AI (also known as Helplytics AI) is a powerful, community-driven support network designed specifically for students, mentors, creators, and builders. Whether you are stuck on a bug, need design feedback, or want to share your expertise, HelpHub AI connects the right problems with the right solvers using intelligent AI matching.

---

## 🌟 Key Features

- **💡 AI Request Intelligence:** Automatically categorizes requests, detects urgency, adds tags, and provides AI-driven rewrite suggestions for better visibility.
- **🤝 Ask & Discover:** Easily structure your requests to attract the right people. Browse the community feed, view helper lists, and interact through a smart notification system.
- **🏆 Community Trust Graph:** A built-in reputation system! Earn trust scores, badges, and rank up on the Leaderboard by solving requests and building your contribution history.
- **💬 Real-Time Collaboration:** Fast interactions designed to move people from "struggling alone" to "solving together".

## 🛠️ Technology Stack

This project is built focusing on a **Pure, Premium, and Modern SaaS Aesthetic** without relying on heavy frameworks. 

- **HTML5:** Semantic and accessible page structuring.
- **CSS3 (Vanilla):** Custom, responsive, and highly-polished styling featuring modern UI patterns (glassmorphism accents, polished typography, and dynamic hover states). **No Bootstrap or Tailwind was used!**
- **JavaScript (Vanilla):** For smooth DOM manipulations, mobile navbar toggling, and interactive components.

## 📂 Project Structure

The project comes with a fully-functional multi-page UX flow:

- `index.html` - The Dashboard / Landing page.
- `helphub-explore.html` - The main feed to explore community requests.
- `helphub_request_detail.html` - Detailed view of individual requests.
- `helphub-leaderboard.html` - Rankings and badges for top community helpers.
- `helphub-notifications.html` - Stay updated on requests, helpers, and trust signals.
- `helphub-messages.html` - In-app messaging interface for direct collaboration.
- `helphub-profile.html` - User profile, portfolio tracking, and trust scores.
- `helphub_aicenter.html` - Access AI summaries, insights, and intelligent request matching.
- `helphub_login.html` - Clean onboarding and login portal.
- `assetes/css/` - Contains all modular custom styling files (`style.css`, page-specific styles, etc.).

## 🚀 How to Run

Because this is a pure HTML/CSS/JS project, setting it up is incredibly easy:

1. **Clone or Download** the repository to your local machine.
2. Navigate to the project folder.
3. Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
4. _(Optional)_ For the best development experience, run it using a local server like **Live Server** in VS Code.
